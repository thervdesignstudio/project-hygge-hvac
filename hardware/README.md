# Project Hygge: Hardware & Physical Enclosures

[![License: CERN-OHL-P v2](https://img.shields.io/badge/Hardware-CERN--OHL--P_v2-blue.svg)](../HARDWARE_LICENSE)

Welcome to the hardware design module for **Project Hygge** / **HICC (Hygge Integrated Climate Control)**. This directory contains all physical CAD models, 3D printing STL/3MF profiles, CNC routing vector files, and physical packaging layouts maintained by **The RV Design Studio**.

All mechanical components are designed to meet strict spatial and thermal constraints for native 24V off-grid travel trailers and van conversions, specifically optimized for lightweight composite panel monocoques and sub-floor installations.

---

## 📐 Spatial Constraints & Manufacturing Specs

The physical hardware architecture is optimized for high-durability, self-fabricated components using additive manufacturing (PETG/ASA) and sheet/panel CNC routing.
